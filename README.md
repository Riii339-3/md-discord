# Discord Rule Manager  

## なあにこれえ⇚初心者が作ったよーわからんやつ  

### 使い方

0. Github Secletにkey`DISCORD_TOKEN`を作り、そこにDiscod Bot Tokenを置く  
1. markdowns/にmdファイルを作り、ルールを記載する  
2. config/markdowns.jsonに送信したいチャンネルのIDとそれに紐づけるpath(**`markdowns/`は記載しない**)を書く  
3. コミットしてGithubにプッシュする  
4. うまくいけばActionsが動くので自動的に送信される  
5. 二回目以降はmdを編集し、コミット&プッシュするだけでメッセージが編集される
